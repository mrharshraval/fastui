# Apple-style Naming
Apply Apple-style naming consistently across the entire Fast UI product.

Use labels that are:
- Short
- Clear
- Familiar
- Action-oriented
- Human-readable
- Free of unnecessary technical or CRM terminology

Prefer the simplest recognizable term over longer descriptive labels.

Examples:
- Filters → Filter
- Lead Status → Status
- Sort → Sort By
- Search country, region, or city… → Search Locations…
- Selected Locations → Selected Locations
- Apply → Done
- View All Leads → remove when unnecessary
- Urgency Status → Status
- Action Attention Hub → Follow-ups

Apply this naming principle to navigation, page titles, buttons, filters, selectors, dropdowns, tabs, table headers, actions, empty states, alerts, and system messages.

Do not invent unnecessarily clever product terminology. Prefer the shortest standard label that clearly communicates the user's action or the content being shown.
