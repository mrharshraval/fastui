# Brainlab 🧠

> A modern, high-performance dental clinic website built with Next.js, Tailwind CSS, and Shadcn UI.

![Project Banner](/public/og-image.png)

## Overview

Brainlab is a premium dental clinic website designed to provide an exceptional user experience. It features a clean, "Zinc" based aesthetic, a powerful command menu for navigation, and a fully responsive mobile-first design.

## ✨ Features

-   **Modern Aesthetics:** A clean, borderless design using the "Zinc" color palette with pastel accents.
-   **Responsive Hero:** A stunning hero section with a stacked layout on mobile for maximum readability.
-   **Command Menu:** A fully custom, keyboard-accessible command menu (`Ctrl+K`) for quick navigation.
-   **Treatments Hub:** A visual grid showcasing cosmetic, orthodontic, and general dental treatments.
-   **Interactive Elements:** Smooth hover effects, micro-animations, and a floating WhatsApp chat button.
-   **Solid Mobile UX:** Optimized for mobile devices with solid backgrounds for readability and touch-friendly targets.

## 🛠️ Tech Stack

-   **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
-   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
-   **UI Components:** [Shadcn UI](https://ui.shadcn.com/)
-   **Icons:** [Lucide React](https://lucide.dev/)
-   **Animation:** [Tailwind CSS Animate](https://github.com/jamiebuilds/tailwindcss-animate)

## 🚀 Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/brainlab.git
    cd brainlab
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Open your browser:**
    Navigate to [http://localhost:3000](http://localhost:3000) to see the application running.
