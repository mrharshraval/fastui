# Contributing to Brainlab

Thank you for your interest in contributing to Brainlab! We welcome contributions from the community to help make this project even better.

## Getting Started

1.  **Fork the repository** on GitHub.
2.  **Clone your fork** locally:
    ```bash
    git clone https://github.com/yourusername/brainlab.git
    ```
3.  **Create a new branch** for your feature or bug fix:
    ```bash
    git checkout -b feature/amazing-feature
    ```

## Development Workflow

1.  **Install dependencies:**
    ```bash
    npm install
    ```
2.  **Run the development server:**
    ```bash
    npm run dev
    ```
3.  **Make your changes.** Please ensure your code follows the existing style and conventions.
4.  **Test your changes.** Verify that everything works as expected on both desktop and mobile.

## Commit Guidelines

-   Use clear and descriptive commit messages.
-   Start your commit message with a verb (e.g., "Add", "Fix", "Update").
-   Reference any relevant issues.

## Pull Requests

1.  **Push your branch** to GitHub:
    ```bash
    git push origin feature/amazing-feature
    ```
2.  **Open a Pull Request** against the `main` branch.
3.  Provide a clear description of your changes and why they are necessary.
4.  Wait for review and address any feedback.

## Code of Conduct

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.

Happy coding! 🚀
