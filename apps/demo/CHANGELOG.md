# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
-   **Command Menu:** A completely redesigned, detached-style command menu (`Ctrl+K`) with "Search..." placeholder and ESC/Close controls.
-   **Mobile Layout:** A new stacked layout for the Hero section on mobile, ensuring text readability with solid backgrounds.
-   **Solid Sections:** Updated Features, Services, and Testimonials sections to have solid backgrounds on mobile and desktop cards, removing transparency issues.
-   **Footer:** A comprehensive footer with quick links, treatments list, and contact info.
-   **Treatments Page:** A dedicated hub for all dental services.

### Changed
-   **Theme:** Migrated to a "Zinc" color palette (Black, White, Gray) for a cleaner, more premium look.
-   **Typography:** Optimized font sizes for better hierarchy and readability across devices.
-   **Navigation:** Renamed "Services" to "Treatments" globally.
-   **Performance:** Optimized image loading and reduced layout shifts.

### Fixed
-   **Mobile Transparency:** Resolved issue where text was hard to read on mobile due to transparent backgrounds over the hero image.
-   **Command Menu Alignment:** Fixed padding and sizing inconsistencies in the search input and result items.
-   **Build Errors:** Resolved duplicate import issues and linting errors.

## [1.0.0] - 2025-11-20
-   Initial Release.
